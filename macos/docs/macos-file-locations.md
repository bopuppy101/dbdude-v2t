# macOS dbdude-v2t File Locations

## User Data Directory
`~/Library/Application Support/dbdude-v2t/`

## JSON Files

| File | Absolute Path | Description |
|------|---------------|-------------|
| custom_mappings.json | `~/Library/Application Support/dbdude-v2t/custom_mappings.json` | User custom word mappings |
| rules.json | `~/Library/Application Support/dbdude-v2t/rules.json` | User-defined formatting rules |

## Map Packs (bundled with app)
`<app_directory>/maps/packs/`

Example: `/Users/<username>/git/dbdude-v2t/macos/maps/packs/`
