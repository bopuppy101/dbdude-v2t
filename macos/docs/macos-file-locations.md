# macOS Voice2Text File Locations

## User Data Directory
`~/Library/Application Support/Voice2Text/`

## JSON Files

| File | Absolute Path | Description |
|------|---------------|-------------|
| custom_mappings.json | `~/Library/Application Support/Voice2Text/custom_mappings.json` | User custom word mappings |
| rules.json | `~/Library/Application Support/Voice2Text/rules.json` | User-defined formatting rules |

## Map Packs (bundled with app)
`<app_directory>/maps/packs/`

Example: `/Users/mike/git/macos-v2t/maps/packs/`
