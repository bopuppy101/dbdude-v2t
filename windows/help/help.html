Voice2Text Help

Voice2Text is a GPU-accelerated voice-to-text tool that lets you speak text directly into any application.

Voice2Text uses an underlying AI model named Faster Whisper. The base model is included with the installer. Voice2Text is optimized for NVIDIA GPUs but will work on CPU alone (with slower performance).

It supports two modes of operation:

  • Interactive Mode — Hold Alt+Shift to record only when you want
  • Hands-Free Mode — Always-recording toggle with Ctrl+Alt+R

1. Installation

  1. Run v2t-setup-2026.exe
  2. Accept the license agreement
  3. Choose installation folder (default: C:\Program Files\voice2text\)
  4. Optionally create a desktop shortcut
  5. Click Install

2. Starting Voice2Text

From the Start Menu

  1. Open the Windows Start Menu
  2. Search for Voice2Text
  3. Click to launch

What Happens at Startup

When Voice2Text launches, it opens a configurator window where you can:

  • Select the Whisper model size
  • Choose your microphone
  • Enable/disable logging
  • Click Start Voice2Text to begin

Voice2Text runs in your Windows system tray. The icon shows the current state:

  • Blue — Ready, waiting for you
  • Green — Recording your voice
  • Amber — Transcribing

3. Interactive Mode (Default)

Action Hotkey
Start recording Hold Alt + Shift
Stop recording & transcribe Release Alt + Shift
Exit program Ctrl + Shift + Q

How it works

  1. Hold Alt+Shift while speaking
  2. Release the keys
  3. Voice2Text transcribes your speech and types it into the active window
Tip: You can use Voice2Text inside any app: ChatGPT, Claude, MS Word, Gmail, VSCode, Slack, Chrome, Notepad — anything!

4. Hands-Free Mode

Hands-Free Mode records continuously until you toggle it off.

Action Hotkey
Toggle Hands-Free Mode ON/OFF Ctrl + Alt + R

Perfect for:

  • Long dictation
  • Meetings
  • Extended writing
  • Hands-free operation

5. All Hotkeys Summary

Feature Hotkey Description
Interactive recording Hold/Release Alt+Shift Speak only when needed
Toggle Hands-Free Mode Ctrl + Alt + R Always-on recording
Exit program Ctrl + Shift + Q Clean shutdown

6. Viewing Your Logs

Logging is disabled by default. To enable logging, check the "Enable Logging" checkbox in the Settings window before clicking "Start Voice2Text".

When logging is enabled, transcribed text is stored in:

C:\Users\<YourName>\logs\

Files look like: snippet_20251216_153422_123456.txt

7. Stopping Voice2Text

Three ways to exit:

  1. Press Ctrl + Shift + Q
  2. Right-click the V2T icon in the system tray and select Exit
  3. Emergency: Ctrl+C in the console window (if visible)

8. Mapping Editor

The Mapping Editor lets you customize how spoken words are transcribed:

  • Correct commonly misheard words (e.g., "postgres" → "PostgreSQL")
  • Add shortcuts for symbols (e.g., "forward slash" → "/")
  • Technical jargon specific to your field

Launch it from the Mapping/Rules button in the settings window, or right-click the systray icon and select Open Mapping/Rules.

Map Packs

Pre-built collections of mappings that ship with Voice2Text:

  • Programmer — Programming symbols (e.g., "open paren" → "(", "backtick" → "`")
  • Punctuation — Spoken punctuation to symbols (e.g., "question mark" → "?")

File Location

Your custom mappings are stored in:

%APPDATA%\Voice2Text\custom_mappings.json

9. Rules

Use Mappings to fix misheard words. Use Rules to control formatting based on conditions.

Conditions

Condition Type Example Description
Word count <= 3 Number of words in the transcription
Starts with Note Transcription begins with specific text
Ends with ? Transcription ends with specific text
Contains edit Transcription contains specific text

Actions

Action Description
Remove trailing punctuation Strips .!?,;: from the end
Add period at end Ensures transcription ends with a period
Lowercase first letter Makes first character lowercase
Uppercase first letter Capitalizes first character

File Location

Rules are stored in:

%APPDATA%\Voice2Text\rules.json

10. System Tray Icon

Icon Color State
Blue Ready — waiting for you to speak
Green Recording — currently capturing audio
Amber Transcribing — processing your speech

Right-Click Menu

  • Show/Hide Console — Toggle the debug console window
  • Open Mapping/Rules — Launch the mapping editor
  • Open Logs Folder — Quick access to your transcription logs
  • Show Help — Open this help document
  • Show Shortcuts — Quick reference for keyboard shortcuts
  • Exit — Clean shutdown of Voice2Text

11. Troubleshooting

Nothing is typing into my window

Make sure the window is focused — Voice2Text types into the active window.

"Started recording…" but nothing transcribes

  • Microphone too quiet
  • Speak a little louder
  • Minimum energy detection is active (to prevent noise)

Program freezes

  • Press Ctrl + Shift + Q
  • Or close the console window

Whisper model loads slowly at startup

Normal — the GPU model must warm up on first run.

Warning: Don't run more than one copy of Voice2Text at a time. If you see two V2T icons in your system tray, right-click one and select Exit.
