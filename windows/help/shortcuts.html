Voice2Text Quick Reference

Keyboard Shortcuts

Action Shortcut
Record (Interactive) Hold Alt + Shift
Stop & Transcribe Release Alt + Shift
Toggle Hands-Free Mode Ctrl + Alt + R
Exit Voice2Text Ctrl + Shift + Q

System Tray Icon Colors

Color Status
Blue Ready — waiting for input
Green Recording — capturing audio
Amber Transcribing — processing speech

Two Recording Modes

Mode How to Use
Interactive Hold Alt+Shift while speaking, release to transcribe
Hands-Free Press Ctrl+Alt+R to start, press again to stop & transcribe

Quick Tips

  • Text is typed into the active window — make sure your target app has focus
  • Speak naturally — Whisper handles punctuation automatically
  • Right-click the tray icon to access Mapping/Rules editor, logs, and help
  • Custom mappings fix misheard words; Rules control formatting

File Locations

File Location
Custom Mappings %APPDATA%\Voice2Text\custom_mappings.json
Rules %APPDATA%\Voice2Text\rules.json
Logs %USERPROFILE%\logs\
